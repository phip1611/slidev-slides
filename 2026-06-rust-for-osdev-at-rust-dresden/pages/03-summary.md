# 3. Summary

<v-clicks depth="2">

- Rust and low-level OS development are a (very productive!) reality
- Many great libraries in the ecosystem
- Makes complexity visible and approachable
- Uncovers many interesting challenges of the hardware reality
- Even challenges Rust itself: UB, memory safety, Miri, memory model
- Where to start? `github.com/rust-osdev`: zulip, community, ...
  - Write an UEFI application
  - Write your minimal kernel
  - And run them in a VM
