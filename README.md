# My Slidev slides

Common repository for my slides/presentations/talks using
<https://sli.dev/>.

## Open (Live Dev Server) or Build (HTML Deployment)

- `$ cd <talk>`
- `$ npm run dev` to serve slides locally
- `$ npm run build` to build a static HTML deployment
